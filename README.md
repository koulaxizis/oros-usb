# orOS USB

A bootable USB image that starts straight into [orOS](https://useoros.online): a minimal Debian (live-build) with a kiosk compositor (cage) and Chromium in app mode, orOS served from the stick on `http://localhost:47800/` by the [orOS Portable](https://github.com/koulaxizis/oros-portable) launcher, and a persistence partition for data. MIT, free forever.

Status: planned, work starts after orOS Portable.
